# AI 作品集 · 求职周报系统

以自己为唯一用户，用 DeepSeek 搭的一套「信息结构化 → 决策自动化 → 记录自动化 → 复盘闭环」的 AI 求职工作流。

## 在线体验（作品演示版）

🔗 https://frabjous-figolla-b0786f.netlify.app

> 演示版内置虚构示例数据，不含任何真实个人信息；你的填写只保存在你自己的浏览器。

## 内容清单

| 文件 | 说明 |
|---|---|
| `使用说明.md` | **怎么使用**：打开方式、快速上手、填写/导入/导出/归档完整步骤 |
| `作品说明.md` / `作品说明.docx` | 项目背景目标、AI 工具与模型选择、与 AI 的分工、核心挑战与解决方案、项目结果 |
| `index.html` | **演示版**（HTML），双击即可体验，内置示例数据 |
| `weekly-report.html` | **正式版源码**（HTML），完整功能单文件 |
| `作品图片/作品集展示图.png` | 一页式作品集海报（定位 / 功能 / 分工 / 成果） |
| `作品图片/界面长图.png` | 系统界面完整长图（已填充示例数据） |

## 打开方式

1. **在线**：直接访问上方链接。
2. **本地**：双击 `index.html`，点「🎬 载入示例数据」查看完整效果。

## 技术说明

- 单文件 HTML + 原生 JS，内联 SheetJS（Excel 解析）与 html2canvas-pro（导出 PNG），零构建、零依赖。
- 数据存于浏览器 localStorage，无后端、不采集数据。
- 支持 Excel/CSV 一键导入面试表、台账 `qiuzhao-ledger.md` 与作战地图数据 `qiuzhao-data.js` 导入/回写，形成数据闭环。
